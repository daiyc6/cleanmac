# macOS 文件与文件夹处置清单

> 研究日期：2026-11-12 · 依据 Apple 官方文档 + 本机实测
> 用途：cleanmac 规则库的数据来源，也可作为人工清理的判据

---

## 0. 判定标准

不是按"能不能删"二分，而是按**删了之后谁来承担后果**分三级：

| 级别 | 含义 | 判定依据 | 默认行为 |
|---|---|---|---|
| **A · 可重建** | 删掉后系统或 App 会自动重新生成 | Apple 文档明确说明该目录用于"可丢弃的数据" | 默认勾选 |
| **B · 需确认** | 删掉会丢配置、登录态或使用痕迹 | 目录里混有用户状态 | 默认不勾 |
| **C · 不可删** | 删掉会丢失不可再生的数据 | 原始照片、邮件、密码、备份 | 界面锁定 |
| **D · 系统级** | 需要 root，且影响面大 | 系统诊断、系统缓存 | 只展示，不操作 |

## 1. 依据

Apple 的 [File System Programming Guide · Library Directory Details](https://developer.apple.com/library/archive/documentation/FileManagement/Conceptual/FileSystemProgrammingGuide/MacOSXDirectories/MacOSXDirectories.html) 对关键目录有明确定义，本清单的 A/B 分级直接引用它：

- **Caches**：*"Contains cached data that can be regenerated as needed. Apps should never rely on the existence of cache files."*
  → 这是 A 级判定的法律依据：连 App 自己都不允许依赖缓存存在。
- **Logs**：*"Contains log files for the console and specific system services."*
  → 排障用，A 级。
- **Application Support**：*"Contains all app-specific data and support files… can include files that contain user data."*
  → **明确包含用户数据，因此不能整体删除**，只能按 App 子目录判断。
- **Preferences**：*"The user's preferences. You should never create files in this directory yourself."*
  → 用户配置，B 级。
- **Containers**：*"Contains the home directories for any sandboxed apps."*
  → 沙盒应用的"家"，里面既有缓存也有用户文件，必须细分。

补充依据：[Apple 支持 · 释放 Mac 上的存储空间](https://support.apple.com/zh-cn/102624)（官方推荐路径：废纸篓、下载项、信息附件、优化照片、卸载不用的 App）。

## 2. A 级 · 可以安全删除

| # | 路径 | 内容 | 删除后果 | 依据 |
|---|---|---|---|---|
| A1 | `~/Library/Caches/*` | 各 App 缓存 | 首次启动变慢，自动重建 | Apple：缓存可重建 |
| A2 | `~/Library/Logs/*` | 应用日志 | 丢失历史排障记录 | Apple：日志定义 |
| A3 | `~/Library/Logs/DiagnosticReports/` | 崩溃报告 | 无法回溯闪退 | 同上 |
| A4 | `~/Library/Application Support/com.apple.wallpaper/aerials/videos/` | 动态壁纸视频 | 再次使用时重新下载 | 可重建资源 |
| A5 | `/private/var/folders/<xx>/<id>/T/` | 用户临时文件 | 运行中的程序可能短暂异常 | Apple：临时目录会被系统清理 |
| A6 | `/private/var/folders/<xx>/<id>/C/com.apple.appstoreagent` | App Store 下载缓存 | 重新下载 | 可重建 |
| A7 | `~/.Trash/*` | 废纸篓 | 无法还原（**这是唯一例外**） | 用户已主动丢弃 |
| A8 | `~/Library/Developer/Xcode/DerivedData/` | 编译中间产物 | 下次编译变慢 | 重新编译即恢复 |
| A9 | `~/Library/Developer/CoreSimulator/Caches/` | 模拟器缓存 | 重新生成 | 同上 |
| A10 | `~/.npm/_cacache` | npm 包缓存 | 重新下载依赖 | 包管理器缓存 |
| A11 | `~/Library/pnpm/store/` | pnpm 内容寻址存储 | 重新链接/下载 | 同上 |
| A12 | `~/.cache/uv/` | uv 包缓存 | 重新下载 | 同上 |
| A13 | `~/Library/Caches/pip/` | pip wheel 缓存 | 重新下载 | 同上 |
| A14 | `~/Library/Caches/Homebrew/` | Homebrew 下载缓存 | 重新下载 | 同上 |
| A15 | `~/.cargo/registry/cache/` | Cargo crate 缓存 | 重新下载 | 同上 |
| A16 | `~/Library/Caches/Google/Chrome/` | Chrome 网络缓存 | 页面重载变慢 | 不含 Cookie/密码 |
| A17 | `~/Library/Caches/Microsoft Edge/` | Edge 网络缓存 | 同上 | 同上 |
| A18 | `~/Library/Caches/com.apple.Safari/` | Safari 缓存 | 同上 | 同上 |

> **A7 的例外**：废纸篓是用户已声明不要的东西，删了不可还原——但它本身已经是"删除的第二站"，所以仍归 A。

## 3. B 级 · 需要确认

| # | 路径 | 内容 | 删除后果 |
|---|---|---|---|
| B1 | `~/Library/Application Support/<bundleID>/` | 各 App 的用户数据 | **可能丢聊天记录、项目文件、登录态** |
| B2 | `~/Library/Preferences/<bundleID>.plist` | 偏好设置 | 恢复默认设置 |
| B3 | `~/Library/Saved Application State/*.savedState` | 窗口恢复状态 | 下次打开不还原窗口 |
| B4 | `~/Library/HTTPStorages/` | App 的 Cookie/会话 | 需要重新登录 |
| B5 | `~/Library/WebKit/` | WebKit 站点数据 | 部分站点需重新登录 |
| B6 | `~/Library/Cookies/` | Cookie 文件 | 需重新登录 |
| B7 | `~/Library/Containers/<bundleID>/Data/Library/Caches/` | 沙盒应用缓存 | 通常安全，但路径在沙盒内需谨慎 |
| B8 | `~/Downloads/*.dmg / *.pkg / *.zip` | 安装包与压缩包 | **用户文件**，只在确认已安装后删 |
| B9 | `~/Library/Application Support/MobileSync/Backup/` | iPhone 备份 | 换机/恢复时无备份可用 |
| B10 | `~/Library/Messages/Attachments/` | 信息附件 | 聊天里的图片视频丢失 |
| B11 | `~/Library/Mail/*/Attachments/` | 邮件附件 | 部分邮件无法离线查看 |

## 4. C 级 · 不可删除（只能迁移或归档）

| # | 路径 | 为什么不能删 |
|---|---|---|
| C1 | `~/Pictures/Photos Library.photoslibrary` | 原始照片与编辑历史，删了不可再生 |
| C2 | `~/Pictures/Photo Booth图库` | 拍摄的原始照片 |
| C3 | `~/Music/Music/Media/` | 音乐资料库（含本地导入的曲目） |
| C4 | `~/Movies/*.imovielibrary` | 影片项目素材 |
| C5 | `~/Library/Keychains/` | 密码、证书、密钥 |
| C6 | `~/Library/Mobile Documents/` | iCloud 云盘，删除会同步到所有设备 |
| C7 | `~/Library/CloudStorage/` | 第三方网盘占位，删了会同步删云端 |
| C8 | `~/Documents` `~/Desktop` `~/Pictures` `~/Movies` `~/Music` | 用户主目录内容 |
| C9 | `~/Library/Application Support/AddressBook/` | 通讯录 |
| C10 | `/Applications/*.app` | 只能"卸载"（连同残留），不能当缓存删 |

## 5. D 级 · 系统级（需 root，不建议）

| # | 路径 | 说明 |
|---|---|---|
| D1 | `/private/var/db/diagnostics/` | 系统诊断日志，通常 1–3 GB，需 root |
| D2 | `/private/var/db/uuidtext/` | 调试符号索引，需 root |
| D3 | `/Library/Caches/` | 全系统缓存，需 admin |
| D4 | `/private/var/log/` | 系统日志，需 root |
| D5 | `/Library/Updates/` | 系统更新残留 |
| D6 | `/System/Volumes/Data/.DocumentRevisions-V100` | 文档版本，root 独占 |
| D7 | `/System/Volumes/Data/.Spotlight-V100` | 索引，可用 `mdutil -E /` 重建 |

> D 级不做自动删除：代价（提权、误删风险）远大于收益。界面上只展示体积并给出可复制命令。

## 6. 特殊判定

| 对象 | 判定 | 说明 |
|---|---|---|
| APFS 本地快照 | 保留 | `tmutil listlocalsnapshots`，删了会失去本地恢复点 |
| `~/Library/Developer/Xcode/Archives` | 保留 | 含 dSYM，删了无法符号化历史崩溃 |
| `~/Library/Developer/CoreDevice/DeviceFS` | 保留 | Xcode 设备挂载点（实测带 `uchg` 标志） |
| Time Machine 备份盘 | 保留 | 不在本机清理范围内 |
| 字体 `~/Library/Fonts` | 需确认 | 你自己装的字体，删了文档会换字体 |

## 7. 三条判定口诀

1. **看语义，不看大小。** `Application Support` 可能只有 10 MB 却是聊天记录；`Caches` 可能 8 GB 但全是可重建数据。
2. **可重建 ⇔ 可删。** 判断标准只有一个：删掉后系统或 App 能不能自己造回来。
3. **不可再生的一律不动。** 照片、邮件、密码、备份、聊天记录——再小也不碰。

## 8. 与 cleanmac 的对应

A 级 → 规则库自动勾选
B 级 → 列出但默认不勾，标注"注意"
C 级 → 界面锁定（`Protection`）
D 级 → 只展示体积

数据文件见 [`resources/rules.json`](../resources/rules.json)。
