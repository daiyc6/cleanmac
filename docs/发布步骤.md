## 第 1 步：在 GitHub 上建一个空仓库

打开 https://github.com/new

| 字段 | 填什么 |
|---|---|
| Repository name | `cleanmac` |
| Description | `免费、开源、不联网的 macOS 空间清理工具` |
| 可见性 | Public |
| Add a README | ❌ **不要勾** |
| Add .gitignore | ❌ **不要勾** |
| Choose a license | ❌ **不要勾** |

> 这三项都不要勾。你本地已经有了，勾了会冲突，push 时会报 `rejected`。

建完会看到一页提示 `git remote add origin ...`，先别关。

---

## 第 2 步：关联远程并推送

把下面命令里的 `<你的用户名>` 换成你的 GitHub 用户名：

```bash
cd ~/Documents/deepseek-harness/default-workspace/cleanmac-app

git remote add origin https://github.com/<你的用户名>/cleanmac.git
git push -u origin main
git push origin v0.1.0
```

第一次 push 会让你认证。用 **Personal Access Token** 当密码（GitHub 早就不支持账号密码了）：

1. 打开 https://github.com/settings/tokens
2. Generate new token → Classic
3. 勾 `repo` 权限 → 生成 → 复制
4. 粘贴到终端的 Password 提示处

> 想省事就用 SSH：`git remote set-url origin git@github.com:<你的用户名>/cleanmac.git`，前提是你已经配过 SSH key。

---

## 第 3 步：发 Release 并上传安装包

1. 打开仓库页面 → 右侧 **Releases** → **Create a new release**
2. **Choose a tag**：选 `v0.1.0`（刚才推上去的）
3. **Release title**：`cleanmac 0.1.0`
4. **Describe this release**：把 `docs/release-v0.1.0.md` 的内容整段粘进去
5. **Attach binaries**：拖入 `dist/cleanmac-0.1.0.dmg`
6. 点 **Publish release**

## 第 4 步：改一处身份信息（重要）

本地提交用的邮箱是个占位符：

```
daiyuancong@users.noreply.github.com
```

**如果你的 GitHub 用户名不是 `daiyuancong`**，这次提交不会关联到你的头像。改一下：

```bash
git config user.email "你的GitHub邮箱"
git commit --amend --reset-author --no-edit
git tag -f v0.1.0
git push -f origin main
git push -f origin v0.1.0
```

如果用户名正好是 `daiyuancong`，忽略这一步。

## 可选：装 gh 用一条命令搞定

如果不想点网页，装 GitHub CLI 之后：

```bash
brew install gh
gh auth login

cd ~/Documents/deepseek-harness/default-workspace/cleanmac-app
gh repo create cleanmac --public --source=. --push
gh release create v0.1.0 dist/cleanmac-0.1.0.dmg \
  --title "cleanmac 0.1.0" \
  --notes-file docs/release-v0.1.0.md
```

两条命令就把第 1–3 步全做了。

## 常见问题

**push 被拒：`rejected (fetch first)`**
建远程仓库时勾了 README 或 license。解决：

```bash
git pull --rebase origin main
git push origin main
```

**认证一直失败**
确认用的是 Token 而不是密码，且 Token 勾了 `repo`。

**截图太大，clone 很慢**
`docs/` 里几张 png 加起来约 12 MB。可以转成 jpg：

```bash
for f in docs/screenshot-*.png; do
  sips -s format jpeg -s formatOptions 80 "$f" --out "${f%.png}.jpg" && rm "$f"
done
```

转完记得改 README 里的引用。

**想改仓库名或描述**
GitHub 网页 → Settings 直接改，remote 地址会自动重定向，不用动本地。

## 之后每次发版

```bash
# 1. 改版本号（build.sh 里的 CFBundleShortVersionString）
# 2. 重新打包
bash build.sh && bash tools/package.sh

# 3. 提交、打标签、推送
git add -A
git commit -m "0.2.0: 加了深色模式"
git tag -a v0.2.0 -m "cleanmac 0.2.0"
git push origin main
git push origin v0.2.0

# 4. 网页上建 Release，上传新的 dmg
```
