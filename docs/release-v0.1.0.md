# cleanmac 0.1.0

我给自己写了个清理工具，现在放出来。

## 起因

我这台 M2 的 mini，盘是 245G。前阵子打开一看，可用空间剩 22G。

系统设置里说用了 183G。我算了算：应用程序 27G，下载文件夹 17G，照片几百兆，加上零零碎碎的，撑死 90G。剩下那九十多个 G，界面上统统归进"系统数据"四个字，点不进去，也查不了。

后来才搞明白，那是 macOS 的隐私保护在挡着。照片图库、邮件、iPhone 备份，没授权的程序一律读不到。读不到就不显示，不显示就跟不存在一样。我试过的几个清理软件都是这样，包括那个一打开就弹"解锁完整版本"的。

## 后来

我先手动清了一遍。翻目录，用 `du` 一个个量，最后腾出来 26G：一个 6G 的系统安装包、几集没看完的剧、五六个 G 的缓存，还有钉钉一个将近 4G 的数据目录。

清完我想，这活儿不该每次都手动干一遍。

## 它现在能做的事

清缓存和日志。这部分没什么争议，删了系统会自己长回来。

看每个应用占多少，而且能分开处理。比如钉钉占 5.7G，其中 4G 是数据，1.5G 是程序。你可以只删那 4G，钉钉还在，下次打开重新登录一下就行。

找大文件。超过 200MB 的，或者一年没打开过的，列出来让你挑。

空间地图能一层层点进去，看清到底哪个文件夹在吃硬盘。

还有一页专门讲"你看不见的空间"，把被系统挡住的目录列清楚，告诉你去哪儿授权。

菜单栏会一直显示还剩多少空间，不用每次开窗口。

## 三件我比较在意的事

**删掉的能捞回来。** 所有删除都是先挪进隔离区，一天内可以还原，一天后自动清掉。想留久一点，设置里能改。

**删不掉的时候，说清楚为什么。** 不弹一句"操作失败"就完了。被哪个程序占着、PID 多少、是文件锁了还是权限不够，都写出来，能给解法的直接给——结束那个程序再试，或者用管理员权限删。

**它不联网。** 代码里没有一处网络请求。想传也传不出去。

## 装之前得说清楚

这版没做公证。苹果开发者年费一年 99 美元，我还没交。

所以第一次打开会看到"无法验证开发者"，这是正常的，不是文件坏了。

两种打开方式，随便选一种：右键点它，选"打开"，再点一次"打开"；或者开终端敲一行

```bash
xattr -dr com.apple.quarantine /Applications/cleanmac.app
```

进去之后首页会让你授权"完全磁盘访问权限"。这个建议给。不给的话，下载、桌面、文稿里的东西它一个都看不到，你会以为这工具没什么用——其实是系统挡着。

## 现在还不行的

没有深色模式。重复文件检测没做。大文件只扫了主目录，没碰系统盘。

未签名的版本每次更新，都得重新走一遍上面那个打开流程。
