## 0. 一句话定位

**一个免费、开源、不联网的 macOS 空间管理工具。**
不判断"你有没有用"，只判断"系统能不能重新造出来"，并且保证每一步都能撤回。

## 3. 安全模型（最核心的部分）

### 3.1 三级判定

| 级别 | 含义 | 默认行为 |
|---|---|---|
| **A · 可重建** | 系统或 App 会自动重新生成 | 默认勾选，可一键清理 |
| **B · 需确认** | 删了会丢配置、登录态 | 默认不勾，必须手动选 |
| **C · 不可删** | 照片、邮件、密码等不可再生数据 | 界面锁定 |

依据：Apple [File System Programming Guide](https://developer.apple.com/library/archive/documentation/FileManagement/Conceptual/FileSystemProgrammingGuide/MacOSXDirectories/MacOSXDirectories.html) 对 `Caches`（可重建）、`Logs`、`Application Support`（**明确含用户数据**）的定义。

### 3.2 隔离区

- 删除 = `moveItem` 到 `~/Library/Application Support/cleanmac/Quarantine/<时间戳>/`
- 写 `manifest.json` 记录原始路径，可原路还原
- **保留期 1 天**（可选 1/3/7/30 天或永不），启动时 + 每小时检查一次，过期自动彻底删除
- 自测保证可逆：`--selftest` 做 移动→校验→还原→校验 的闭环

### 3.3 保护清单（`Protection.reason`）

| 类别 | 判定 |
|---|---|
| 资料库包 | `.photoslibrary` / `.photolibrary` / `.musiclibrary` / `.tvlibrary` / `.imovielibrary` / `.aplibrary` / `.fcpbundle` |
| 资料库内部 | 路径任一层是上述包 ⇒ 内部文件同样禁止 |
| 无扩展名图库 | 目录名以「图库」结尾，或含 photo 的 `*library` |
| 用户核心目录 | `~`、`~/Library`、`~/Documents`、`~/Desktop`、`~/Pictures`、`~/Movies`、`~/Music` |
| 不可替代数据 | 钥匙串、iCloud 云盘、网盘同步、iPhone 备份、邮件、信息 |
| 系统 | `/System`、`/usr`、`/bin`、`/Library`、`/Applications` 本身 |

### 3.4 文件标志位（三种"不可变"不是一回事）

| 标志 | 值 | 谁能清 | 我们的处理 |
|---|---|---|---|
| `UF_IMMUTABLE` | `0x2` | 所有者 | 解除锁定后重试 |
| `SF_IMMUTABLE` | `0x20000` | 仅 root | 管理员删除（先 `noschg` 再 `rm`） |
| `SF_RESTRICTED` | `0x80000` | 无人可清（SIP） | 不提供假方案，如实说明 |

> 关键认知：Finder「显示简介」里的「已锁定」勾选框，底层就是 `uchg`。

### 3.5 删除失败的处理

失败不是终点。每项失败都会：诊断原因 → 给出可执行的解法 → 一键执行。

| 诊断 | 解法 |
|---|---|
| 文件已不存在 | 刷新列表 |
| 不可变（uchg） | `chflags nouchg` 后重试 |
| 系统级不可变（schg） | 管理员删除 |
| SIP 保护 | 不提供方案 |
| 隐私保护目录 | 打开完全磁盘访问设置 |
| 被进程占用 | 优雅退出 → 强制退出 → SIGTERM → 重试 |
| 权限不足 | 以管理员删除（唯一不可逆路径，需二次确认） |

## 5. 功能模块

| 页面 | 能力 |
|---|---|
| 概览 | 大字号可清理量 +「立即清理」一步到位；个人文件单独提示 |
| 清理 | 上半「系统数据」一键清（无确认）/ 下半「你的文件」勾选 + 确认 |
| 应用程序 | 每行两个动作：删数据（留 App）/ 删 App（留数据）；底部「清理所选」 |
| 大文件 | ≥200 MB 或一年未访问；明示无法读取的目录数 |
| 空间地图 | 可逐层下钻、面包屑、小项聚合（>36 项合并）、勾选删除 |
| 隐形空间 | TCC 受保护目录清单 + 授权引导 |
| 设置 | 背景通透度、隔离区、自动清理、关于 |
| 菜单栏 | 常驻显示可用空间，可清理 / 打开 / 退出 |

### 5.1 应用数据识别

三重键匹配：完整 Bundle ID、末段、应用名。

| 可信度 | 判定 | 默认 |
|---|---|---|
| 精确 | 固定路径，或目录名与键**完全相等** | 参与清理 |
| 疑似 | 目录名**包含**片段（键长 ≥8） | 需手动勾「含疑似」 |
| 受保护 | 存在但读不到（TCC） | 只显示 |

短键只允许全等，防止 `Code` 误伤 `CodeBuddy`；需要下钻 `.localized/Foo.app`（钉钉就是这种结构）。

## 5.2 首启引导

首次启动在概览页顶部显示三步引导：**打开系统设置 → 勾选 cleanmac → 回来点「已授权」**。

- 启动时**不主动探测** TCC 目录（否则会弹系统授权框，很突兀）
- 只有用户点「已授权」才验证一次（尝试读 `~/Downloads`），通过则标记完成并重新扫描
- 「以后再说」也会记住，不反复打扰
- 设置页保留「完全磁盘访问权限」入口，可重新显示引导

## 6. 界面

### 6.1 视觉语言

- **Liquid Glass，用系统原生 API**：`glassEffect(.regular, in: .rect(cornerRadius:))`，macOS 26+ 启用，14–15 回退到 `ultraThinMaterial`
- 窗口 `isOpaque = false` + `NSVisualEffectView(.underWindowBackground)`，整窗透出桌面
- **不铺大面积色块**：全窗着色仅 8%
- 侧栏只用系统材质，不加白色叠加、不画分割线
- 只有卡片是玻璃，其余通透
- 唯一强调色：系统蓝 `#0071E3`

### 6.2 通透度可调

设置页「背景通透度」滑块（15%–70%），默认 **45%**，记在 `UserDefaults`，拖动即时生效。

> 教训：玻璃的前提是"后面有东西可透"。纯色背景上的玻璃只是一块灰板。

### 6.3 交互原则

| 区域 | 操作 |
|---|---|
| 系统数据 | 点「全部清理」直接执行，**不弹确认** |
| 用户文件 | 必须逐项勾选 + 二次确认 |

## 8. 已知限制

1. **TCC 盲区**：`~/Downloads`、`~/Desktop`、`~/Documents`、照片图库等未授权时读不到，文件会"消失"（已用提示条明示 691 个目录受阻）。
2. **疑似匹配有误伤风险**：按目录名反查，短键已限制为全等，但仍非 100%。
3. **大文件只扫主目录**：不含 `/Applications` 与系统盘。
4. **macOS 移动已打开的文件通常成功**：POSIX rename 不受 fd 影响，所以"文件正在使用"很少真正阻塞删除。
5. **管理员删除不可逆**：唯一绕过隔离区的路径，已明确警告。
