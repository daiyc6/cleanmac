# cleanmac 界面设计：四个方向

研究时间：2026-11-12

## 一、研究结论

### 1. Apple 的官方方向：Liquid Glass（2025 年 6 月发布）

Apple 在 WWDC25 公布了统一全平台的新设计语言，macOS 26（Tahoe）同步采用。核心是：

- **半透明材质**：界面元素像玻璃一样浮在内容之上，背景色彩透过来
- **内容优先**：控件退后，数据与内容占据视觉重心
- **层次与深度**：用模糊、内高光、柔和阴影表达层级，而不是用线框

来源：[Apple Newsroom · 新软件设计](https://www.apple.com.cn/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/)

### 2. 2026 年通用 UI 趋势

行业综述里被反复提到的几条：

| 趋势 | 对 cleanmac 的意义 |
|---|---|
| 超个性化仪表盘 | 概览页只呈现"你能清理多少"，而不是罗列功能 |
| 微交互 | 按钮按下缩放、数字变化、清理完成的轻反馈 |
| 3D 与层次 | 卡片浮起、玻璃材质（与 Liquid Glass 同向） |
| 隐形的界面 | 一键完成，不弹确认——正是你要的"一步到位" |
| 无障碍 | 对比度必须够，小字不能到看不清 |

来源：[优设 · 2026 年值得关注的 10 个 UI 设计趋势](https://www.uisdc.com/2026-ui-design)

## 二、四个样稿

| 代号 | 风格 | 一句话 |
|---|---|---|
| **A** | Liquid Glass | 跟着 macOS 26 走，玻璃卡片浮在彩色背景上 |
| **B** | Studio Dark | Linear / Raycast 那种深色工具感，冷静、克制 |
| **C** | Paper Editorial | 暖白纸面 + 衬线数字，像一本印刷手册 |
| **D** | Bento | 模块化拼贴，彩色信息块，亲和、年轻 |

## 三、我的判断

- **A 最"Apple"**，也最贴合 macOS 26 的官方语言，但玻璃材质在浅色桌面下对比度会打折，对文字排版要求高。
- **B 最适合工具类**，长时间看不累，开发者群体接受度高，但和系统其余部分风格割裂。
- **C 最有个性**，辨识度最高，但衬线数字在中文环境里显得文艺过头，工具属性被削弱。
- **D 最稳妥**，接受度广、信息密度好，但"Apple 感"偏弱，更像网页产品。

如果要我只选一个：**A 做主线，吸收 D 的信息密度**——玻璃卡片 + 分区明细，既符合系统方向，又不空。
